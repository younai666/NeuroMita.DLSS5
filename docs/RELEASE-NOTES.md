## 中文

### NeuroMita DLSS5 `<VERSION>` — `<DATE>`

一句话：把 **DLSS 5 神经渲染**做成 NeuroMita **游戏自带设置菜单**里的一页设置（`设置 → 图像 → DLSS5 神经渲染 → DLSS5 设置`），不用 ReShade 那套独立浮层；开关与全部参数直接落盘到 Feeder / RenoDX 的配置，并带防抖、看门狗与自愈。

#### 本次要点（1.0.0）

**内置 L1/L2 设置菜单**

- **L1 入口行** `DLSS5 神经渲染` 注入到游戏原生「图像」页（位于 `窗口化` 与 `垂直同步` 之间）。
- **L2 参数页** `DLSS5 设置`：标题正下方是 `返回`，其后是 11 行参数；行样式、勾选动画、导航（鼠标/键盘/手柄）全部复用游戏控件，不新增任何浮层。
- `返回` 放在标题之下是刻意的：这些页面底部会被面板裁掉（实测可见区到 `y ≈ -670`），放最下面点不到。

**11 项参数**

| 显示名 | 底层键 | 配置文件 | 生效 |
|---|---|---|---|
| 神经渲染总开关 | `mode`（`2` 开 / `0` 关） | `dlss5-feed.cfg` | 即时 |
| 工作分辨率 | `work_resolution`（50–100%） | `dlss5-feed.cfg` | 即时 |
| 锐化 | `work_sharpness`（0–1） | `dlss5-feed.cfg` | 即时 |
| DLSS 预设 | `preset`（0–11） | `dlss5-feed.cfg` | 即时 |
| NR 风格 | `NRLookMode`（0–2） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| NR 强度 | `NRIntensity`（0–2） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| 局部色调强度 | `NRLocalTone`（0–2） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| 局部结构强度 | `NRLocalStructure`（0–2） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| 皮肤结构强度 | `NRSkinStructure`（−1–2，`-1` = 关闭） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| 自动遮罩 | `NRAutoMask`（0/1） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |
| Multi Pass | `NRPasses`（1–10） | `ReShade.ini [RenoDX.DLSS5]` | **重启游戏** |

即：**4 项走 DLSS5-Feeder（含总开关，即时生效）+ 7 项走 RenoDX（重启生效）**。

**总开关走 `mode`，绝不写 `enabled=0`**

实测结论：Feeder 一旦读到 `enabled=0`，会连**配置文件监视**一起停掉（`dlss5-feed.log` 在 `config: enabled=0` 之后再无任何输出），此后写 `enabled=1` 也不会被读到，只能重启游戏。因此本插件的总开关驱动 `mode`（`2` ↔ `0`），`enabled` 全程保持 `1`。

**稳定性机制**

- **800 ms 防抖**：连点只算一次，避免快速 0/1 翻转撞上 effect runtime 重建导致喂帧卡死。
- **喂帧看门狗与自愈**：开启后 8 s 内 `dlss5-feed.log` 没有新活动 → 自动 `mode 0→2` 循环（2.5 s 间隔）→ 仍无活动则 `rebuild++` 强制重建 NGX 特征 → 最后明确报错。
- **真实状态可见**：总开关行标签显示 `[运行中]` / `[已停止]`，依据是日志活动增量而不是配置标志位。
- **标签漂移自愈**：游戏本地化会覆盖我们行的标签（实测出现过 `窗口化`、`Fatigue reserve`），插件在 `OnEnable` / `RefreshVisuals` / `RefreshLocalizedTexts` 三个钩子 + 每 2 s 巡检里拉回。
- **字体同步**：从图形页克隆来的行（`返回` 等）缺字体导致文字不可见；页面可见后（游戏已套用中文）从模板行同步字体到所有行。

**可选：ReShade 启动横幅补丁**

- 现象：每次进入游戏，屏幕顶部出现 ReShade 的启动横幅（`ReShade 6.8.0 / 访问 https://reshade.me ...`）。
- 原因：ReShade 6.8 的 splash **没有任何配置开关**（源码确认：初始着色器编译期间绘制 + 编译后 5 秒内绘制，且 splash 窗口强制 `Alpha=1.0`，因此调透明度/字号也无效）；用 `NoReloadOnInit=1` 跳过初始效果加载虽然能去掉横幅，但会让 DLSS5 直接失效（实测 `DLSS5_Feed.fx technique MISSING`）。
- 方案：对本地 `dxgi.dll` 打**单点跳转补丁**，把绘制守门跳转改为无条件跳过：

  ```
  0xD08E4: 0F 84 E7 09 00 00  →  E9 E8 09 00 00 90
  ```

- 脚本：`tools\Patch-ReShadeSplash.ps1`（打补丁前自动备份 `dxgi.dll.bak`，支持 `-Restore` 还原；补丁只影响本地这份 ReShade 副本，不影响 DLSS5 渲染链路）。

#### 安装（三种方式）

1. **一键**：把包解压到游戏根目录（含 `NeuroMita.exe` 那层），双击 `install.bat`，按提示走。
2. **手动**：把 `NeuroMita.DLSS5.dll` 复制到 `BepInEx\plugins\`，重启游戏即可。
3. **从源码构建**：

   ```powershell
   dotnet build src/NeuroMita.DLSS5/NeuroMita.DLSS5.csproj -c Release -p:GameDir="<游戏目录>"
   # 产物：src/NeuroMita.DLSS5/bin/Release/NeuroMita.DLSS5.dll
   ```

#### 前置条件

- Windows 10 / 11 **x64**。
- **NVIDIA RTX**：神经模型（`nvngx_dlssnr` 310.8.x）**只在 RTX 50 上能创建神经特征**；RTX 20/30/40 只有 DLAA，没有神经渲染。
- **驱动**：官方口径要求 **≥ 616.56**；本项目在 **610.74** 上实测可用（走 RenoDX 签名 snippet 路径），仍建议升级。
- **BepInEx 6.0.0-be.788**（IL2CPP），并已启动过一次游戏以生成 `BepInEx\interop\`。
- **ReShade 6.8（add-on 构建）+ DLSS5-Feeder + RenoDX DLSS5 消费端 + 两个 NGX 运行时**。
- ⚠️ **本仓库不分发 NVIDIA 运行时**（`nvngx_dlss.dll` / `nvngx_dlssnr.dll`）与消费端插件，请从各自官方渠道获取并按 DLSS5-Feeder 的说明安装。

#### 卸载

1. 删除 `BepInEx\plugins\NeuroMita.DLSS5.dll` 与 `BepInEx\config\nm.dlss5menu.cfg`。
2. 若打过横幅补丁：运行 `tools\Patch-ReShadeSplash.ps1 -Restore`，或用备份的 `dxgi.dll.bak` 覆盖 `dxgi.dll`。
3. 若要连 DLSS5 渲染链路一起移除，按 DLSS5-Feeder 文档删除 ReShade/Feeder/消费端相关文件（`dxgi.dll`、`dlss5-feed.addon64`、`renodx-dlss5.addon64`、`reshade-shaders\`、`ReShade*.ini`、`dlss5-feed.cfg/log`、`nvngx_dlss*.dll`）。
4. 游戏本体数据不会被修改，删除插件后即恢复原状。

#### 已知问题

- **RenoDX 类参数必须重启游戏**才生效：它只在加载时读一次 `ReShade.ini`，改完关开总开关**不会**让它重读（实测 telemetry 中 `look` / `intensity` 不变）。
- **`enabled` 恒为 `1`**：任何工具/脚本都不要把 `dlss5-feed.cfg` 的 `enabled` 写成 `0`，否则 Feeder 会停止监视配置，只能重启游戏恢复。
- **32 位 / DX9 / Vulkan 不适用于本项目**：菜单集成只在 64 位 **D3D11** 构建上验证（Feeder 本身支持更多组合，但不在本项目验证范围）。
- 参数生效代价：DLAA + 神经渲染在 1080p 下约 **78 fps**（关闭时约 **230 fps**），神经渲染约 **8–13 ms/帧**——这是"画质换帧数"。
- 工作是降采样再回扩时（工作分辨率 < 100%）会损失锐度，行标签会提示"降锐度"；`work_resolution` 是成本旋钮，不是 DLSS 超分。

## Русский

### NeuroMita DLSS5 `<VERSION>` — `<DATE>`

Коротко: **DLSS 5 Neural Rendering** превращён в страницу **штатного меню настроек** NeuroMita (`Настройки → Изображение → DLSS5 神经渲染 → DLSS5 设置`) — без отдельного оверлея ReShade. Переключатель и все параметры пишутся прямо в конфиги Feeder / RenoDX, плюс антидребезг, сторож подачи кадров и самовосстановление.

#### Главное в этом выпуске (1.0.0)

**Встроенное меню L1/L2**

- **Строка входа L1** `DLSS5 神经渲染` внедряется в родную страницу «Изображение» (между `窗口化` и `垂直同步`).
- **Страница параметров L2** `DLSS5 设置`: сразу под заголовком — `返回`, далее 11 строк параметров; стиль строк, анимация галочки и навигация (мышь/клавиатура/геймпад) используют штатные элементы игры, новых оверлеев нет.
- `返回` намеренно расположена под заголовком: низ этих страниц обрезается панелью (по замерам видимая область до `y ≈ -670`), и в самом низу до неё не нажать.

**11 параметров**

| Отображаемое имя | Базовый ключ | Файл конфигурации | Применение |
|---|---|---|---|
| 神经渲染总开关 | `mode` (`2` вкл / `0` выкл) | `dlss5-feed.cfg` | сразу |
| 工作分辨率 | `work_resolution` (50–100%) | `dlss5-feed.cfg` | сразу |
| 锐化 | `work_sharpness` (0–1) | `dlss5-feed.cfg` | сразу |
| DLSS 预设 | `preset` (0–11) | `dlss5-feed.cfg` | сразу |
| NR 风格 | `NRLookMode` (0–2) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| NR 强度 | `NRIntensity` (0–2) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| 局部色调强度 | `NRLocalTone` (0–2) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| 局部结构强度 | `NRLocalStructure` (0–2) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| 皮肤结构强度 | `NRSkinStructure` (−1–2, `-1` = выкл) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| 自动遮罩 | `NRAutoMask` (0/1) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |
| Multi Pass | `NRPasses` (1–10) | `ReShade.ini [RenoDX.DLSS5]` | **после перезапуска игры** |

То есть: **4 параметра идут через DLSS5-Feeder (включая главный переключатель, применяются сразу) + 7 через RenoDX (нужен перезапуск игры)**.

**Главный переключатель работает через `mode`, `enabled=0` не пишется никогда**

Проверено на практике: как только Feeder прочитает `enabled=0`, он останавливает **и слежение за файлом конфигурации** (после `config: enabled=0` в `dlss5-feed.log` больше нет ни одной строки), и последующая запись `enabled=1` уже не будет прочитана — помогает только перезапуск игры. Поэтому главный переключатель управляет `mode` (`2` ↔ `0`), а `enabled` всё время остаётся `1`.

**Механизмы устойчивости**

- **Антидребезг 800 мс**: повторные нажатия считаются одним, чтобы быстрые переключения 0/1 не столкнулись с пересозданием effect runtime и не «заморозили» подачу кадров.
- **Сторож подачи кадров**: если в течение 8 с после включения в `dlss5-feed.log` нет новой активности → автоматически выполняется цикл `mode 0→2` (интервал 2.5 с) → если активности всё ещё нет, `rebuild++` принудительно пересоздаёт функцию NGX → в конце явная ошибка в журнале.
- **Видимый реальный статус**: подпись строки переключателя показывает `[运行中]` / `[已停止]` по приросту активности в журнале, а не по флагу конфигурации.
- **Самовосстановление подписей**: локализация игры перезаписывает подписи наших строк (на практике появлялись `窗口化`, `Fatigue reserve`); плагин возвращает их через хуки `OnEnable` / `RefreshVisuals` / `RefreshLocalizedTexts` и обход каждые 2 с.
- **Синхронизация шрифта**: строки, склонированные со страницы графики (`返回` и др.), оставались без шрифта и были невидимы; после появления страницы (когда игра уже применила китайский) шрифт копируется на все строки со строк-шаблонов.

**Опционально: патч стартового баннера ReShade**

- Симптом: при каждом запуске игры сверху появляется стартовый баннер ReShade (`ReShade 6.8.0 / 访问 https://reshade.me ...`).
- Причина: у splash в ReShade 6.8 **нет никакого параметра конфигурации** (подтверждено по исходникам: он рисуется во время первоначальной компиляции шейдеров и ещё 5 секунд после, а окну splash принудительно задаётся `Alpha=1.0`, поэтому прозрачность и размер шрифта не помогают); `NoReloadOnInit=1` убирает баннер, но ломает DLSS5 (на практике `DLSS5_Feed.fx technique MISSING`).
- Решение: точечный патч перехода в локальном `dxgi.dll` — условный переход отрисовки заменяется на безусловный пропуск:

  ```
  0xD08E4: 0F 84 E7 09 00 00  →  E9 E8 09 00 00 90
  ```

- Скрипт: `tools\Patch-ReShadeSplash.ps1` (перед патчем создаёт резервную копию `dxgi.dll.bak`, поддерживает `-Restore`; патч затрагивает только локальную копию ReShade и не влияет на цепочку рендеринга DLSS5).

#### Установка (три способа)

1. **В один клик**: распакуйте пакет в корень игры (туда, где `NeuroMita.exe`) и запустите `install.bat`, следуя подсказкам.
2. **Вручную**: скопируйте `NeuroMita.DLSS5.dll` в `BepInEx\plugins\` и перезапустите игру.
3. **Сборка из исходников**:


#### Требования

- Windows 10 / 11 **x64**.
- **NVIDIA RTX**: нейронная модель (`nvngx_dlssnr` 310.8.x) **создаёт нейронную функцию только на RTX 50**; на RTX 20/30/40 доступен только DLAA, без нейронного рендеринга.
- **Драйвер**: официально требуется **≥ 616.56**; проект проверен на **610.74** (работает через путь подписанного snippet в RenoDX), но обновление рекомендуется.
- **BepInEx 6.0.0-be.788** (IL2CPP), игра запускалась хотя бы раз, чтобы создался `BepInEx\interop\`.
- **ReShade 6.8 (сборка add-on) + DLSS5-Feeder + потребитель RenoDX DLSS5 + два рантайма NGX**.
- ⚠️ **Этот репозиторий не распространяет рантаймы NVIDIA** (`nvngx_dlss.dll` / `nvngx_dlssnr.dll`) и плагин-потребитель: берите их из официальных источников и устанавливайте по инструкции DLSS5-Feeder.

#### Удаление

1. Удалите `BepInEx\plugins\NeuroMita.DLSS5.dll` и `BepInEx\config\nm.dlss5menu.cfg`.
2. Если применялся патч баннера: запустите `tools\Patch-ReShadeSplash.ps1 -Restore` либо восстановите `dxgi.dll` из резервной копии `dxgi.dll.bak`.
3. Если нужно убрать и всю цепочку DLSS5, удалите по документации DLSS5-Feeder файлы ReShade/Feeder/потребителя (`dxgi.dll`, `dlss5-feed.addon64`, `renodx-dlss5.addon64`, `reshade-shaders\`, `ReShade*.ini`, `dlss5-feed.cfg/log`, `nvngx_dlss*.dll`).
4. Данные самой игры не изменяются — после удаления плагина игра возвращается к исходному виду.

#### Известные проблемы

- **Параметры RenoDX требуют перезапуска игры**: потребитель читает `ReShade.ini` только один раз при загрузке, и выключение/включение главного переключателя **не** заставляет его перечитать значения (по телеметрии `look` / `intensity` не меняются).
- **`enabled` всегда `1`**: никакие инструменты и скрипты не должны записывать `enabled=0` в `dlss5-feed.cfg` — Feeder перестанет следить за конфигурацией, и восстановить подачу кадров можно будет только перезапуском игры.
- **32-битные сборки / DX9 / Vulkan не поддерживаются этим проектом**: интеграция меню проверена только на 64-битной сборке с **D3D11** (сам Feeder поддерживает больше комбинаций, но они вне области проверки проекта).
- Цена параметров: DLAA + нейронный рендеринг при 1080p даёт около **78 fps** (при выключении — около **230 fps**), нейронный рендеринг стоит примерно **8–13 мс/кадр**. Это «качество в обмен на кадры».
- При работе с понижением и обратным расширением (рабочее разрешение < 100%) теряется резкость; подпись строки показывает предупреждение «降锐度». `work_resolution` — это регулятор стоимости, а не апскейл DLSS.
